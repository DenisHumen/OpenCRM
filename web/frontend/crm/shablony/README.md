# Шаблоны на будущее — переведённые, но ещё не поставленные

Здесь лежат чужие компоненты (uiverse.io и подобные), которые владелец выбрал,
а места в системе им пока нет. Каждый **уже переведён** на наш язык: без
Tailwind, чистый CSS, цвета — нашими токенами, движение — с веткой
`prefers-reduced-motion`. Поведение — как у образца, один в один; отличаются
только цвета и размеры под нашу палитру.

Каталог лежит **вне `src/`** намеренно: сборка его не берёт, а сторожа
`tests/test_screens.py` и `tests/test_stili_ekranov.py` обходят только `src/`,
потому что здесь классы ещё не связаны с разметкой экранов, а токены
подставлены запасными значениями, чтобы файл открывался в браузере сам по себе.

## Как посмотреть

Открыть `.html` в браузере — файл самодостаточен. Запасные значения токенов в
начале каждого файла повторяют тёмную палитру `src/styles.css` приблизительно;
в системе они берутся из настоящей палитры.

## Как поставить в систему

Порядок — `docs/dizayn/18-chuzhie-komponenty.md`, коротко:

1. блок `<style>` переносится в `src/styles.css` (запасные `:root` не берутся —
   токены там уже есть; если нужен новый, заводится в обеих палитрах);
2. разметка идёт в экран или компонент, классы — те же;
3. новые тексты — в `lib/i18n.ts`, в обоих языках;
4. строка переезжает из таблицы ниже в таблицу «Что уже переведено» в docs/18.
