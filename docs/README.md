## Глоссарий

| Термин | Значение |
|---|---|
| **Клиент** | Запись в CRM: человек или компания, с которыми работает студия. Клиенты **не имеют** аккаунтов в системе. |
| **Сотрудник** | Пользователь системы с аккаунтом: root или менеджер. |
| **Root** | Встроенный суперпользователь. Всегда существует, имеет полный доступ, одобряет аккаунты сотрудников, управляет настройками сайта. |
| **Менеджер** | Сотрудник: ведёт клиентов, создаёт доски, загружает работы, формирует публичные ссылки. |
| **Доска (board)** | Коллекция работ, оформленная для показа клиенту. Имеет заголовок, описание, обложку и набор работ. |
| **Работа (work)** | Единица контента на доске: изображение или видео + название и описание. |
| **Публичная ссылка (share link)** | Уникальный URL доски для клиента. Отзываемая, с опциональным сроком действия и PIN-кодом. Открывается без регистрации. |
| **Витрина (showcase)** | Публичная страница доски, которую видит клиент по ссылке. Лицо проекта. |
